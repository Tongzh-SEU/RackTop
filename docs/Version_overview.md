# RackTop 版本更新

面向用户的简明更新说明，最新版本位于最上方。

## 1.23.0

- 新增项目关联模型，支持像数据集一样长期保存多个模型依赖。
- 支持检查关联模型在项目目标服务器上的副本状态。
- 支持“保存并同步”时只补齐缺失的关联模型副本。
- 项目卡片新增关联模型及其缺失、待检测状态。
- 启动前检查新增关联模型路径和按需同步。
- 修复关联资源缺少目标路径时仍可继续启动任务的问题。
- 支持删除模型或数据集后自动清理项目中的失效关联。

## 1.22.0

- “我的项目”新增模型分类、数量和空状态。
- 支持添加、编辑和移除模型同步对象。
- 支持为模型选择主服务器、目标服务器和独立副本目录。
- 支持模型状态检查、批量同步、单目标同步与暂停/继续。
- 新增 `Llama-3-8B` 模型样例，演示已同步和待创建副本状态。

## 1.21.0

- 新增完整 Shell 启动命令解析，保留环境变量、Conda 和训练命令结构。
- 支持按所选项目和 GPU 自动替换工作目录与 `CUDA_VISIBLE_DEVICES`。
- 新增项目日志路径识别，并将 RackTop 受管日志同步到项目日志位置。
- 新增训练超参数解析和可展开的名称、值编辑列表。
- 新增以项目为主导的启动配置工作区，每个项目单独管理可复用命令和超参模板。
- 支持从项目配置调整本次运行的服务器、项目副本目录、GPU 卡号和超参。
- 新增独立“添加配置”操作，无需立即启动任务即可保存模板。
- 新增默认开启的“是否独占”GPU 筛选。
- 优化启动配置页为项目导航与模板摘要布局，减少命令列截断和无效留白。
- 优化服务器摘要为 GPU 数量与可用/总量系统内存。
- 优化 GPU 摘要为可用/总量显存，并明确标记 MEM。
- 统一资源筛选为 GPU 数量、最低空闲显存和是否独占三列。
- 修复粘贴命令后原始环境变量、日志和训练命令丢失的问题。
- 修复 Conda 参数被误识别为训练超参数的问题。
- 修复启动配置和超参数区域行高过大、信息层级松散的问题。
- 修复“是否独占”与相邻资源筛选项标题和高度不一致的问题。
- 优化启动弹窗宽度，减少超参数和值区域的无效留白。
