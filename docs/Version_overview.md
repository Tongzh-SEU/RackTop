# RackTop 版本更新

面向用户的简明更新说明，最新版本位于最上方。

## 1.17.0

- 新增“我的项目”页面，统一管理跨服务器项目与数据集。
- 支持为每个同步对象指定一台主服务器和多台目标服务器。
- 支持自动查找各服务器 Home 目录内的同名文件或目录。
- 支持输入目录时按当前服务器实时联想远端路径。
- 支持为每台目标服务器单独修改同步路径。
- 支持项目关联零个或多个数据集，并双向展示附属关系。
- 关联数据集不会随项目自动同步，仍由用户单独触发。
- 支持一键将主服务器内容安全同步到指定目标服务器。
- 新增项目优先、数据集在后的响应式瀑布流布局。
- 支持仅移除同步配置而不删除服务器上的文件。

## 1.16.1

- 修复外观设置中同层级标题出现黑灰两种颜色的问题。

## 1.16.0

- 新增紧凑和扩展两种 macOS 菜单栏状态模式。
- 支持在扩展模式中用图标和数字显示待处理预约与异常进程。
- 支持从菜单栏直接打开预约中心或“我的进程”。
- 优化菜单栏状态更新，避免闪烁和计数变化导致的宽度跳动。
- 修复手动结束进程被误认为意外退出的问题。
- 修复 1 天和 3 天 GPU、CPU 趋势将长期分桶误判为缺失数据的问题。
- 统一 1 天和 3 天趋势为 10 分钟平均线与最低、最高极值带。
- 新增右上角手动重连的服务器完成进度提示。
- 统一菜单栏模式选项与其他设置项的字号和字重。
- 修复 GPU 或 CPU 趋势切换到 1 天、3 天时界面卡顿的问题。
- 优化实时刷新期间的历史图表，避免未变化的数据重复计算。
